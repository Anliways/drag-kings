2D 短程直线加速赛（Drag Racing）网页游戏。402 米（四分之一英里）一决胜负，
核心玩法 = **起步弹射时机 + 完美换挡 + 油门防打滑**，配合改装成长与 10 个递增难度对手。

## 运行

方式一（推荐）：直接玩线上版 [https://anliways.github.io/drag-kings/](https://anliways.github.io/drag-kings/)

方式二（本地，任意静态服务器）：

```bash
cd drag-racing
python3 -m http.server 8901
# 打开 http://127.0.0.1:8901
```

方式三：直接双击 `index.html` 也可以玩（无构建、无外部依赖；PWA/Service Worker 仅在 http(s) 下启用）。

### 安装为桌面/手机应用（PWA）

通过 HTTP 访问时游戏自动启用 PWA 能力（`file://` 直开时自动禁用，功能不受影响）：

- **安装**：Chrome/Edge 地址栏的"安装"图标，或菜单里的"安装应用"；Android 为"添加到主屏幕"。
- **独立窗口**：安装后以无地址栏的独立窗口启动（standalone）。
- **离线可玩**：Service Worker 预缓存全部代码与素材，断网也能完整游玩；进度存 localStorage。
- **版本更新**：发新版本时（改动 `sw.js` 的 `VERSION`），旧窗口会弹出"已更新到新版本"提示，重开即用新版。
- 启动画面点击任意处开始（同时解锁音频）；主菜单可一键 ⛶ 全屏。

### 横屏 / 竖屏自适应

手机横竖屏均可游玩，旋转时**平滑重排、比赛状态不丢失**（物理与布局解耦，`resize` 重建夜景缓存）：

- **横屏**：标准布局——天空 44%，双车道居中，仪表盘贴底。
- **竖屏**：压缩天空（地平线抬升至 34%）、双车道紧随其后，仪表盘自动上移到底部触控区之上（与油门/升挡/氮气按钮零重叠），车辆按屏幕宽度重新定标保持视觉占比一致。
- 触屏操作逻辑两个方向完全一致（左 SHIFT / 右 GAS+NOS）；菜单与改装间为流式布局，任意宽度自适应。

## 操作

| 操作 | 按键 | 触屏 |
|---|---|---|
| 油门（按住） | `空格` / `↑` / `W` | 右下角 GAS 圆钮 |
| 升挡 | `F` / `Shift` / `Enter` / `→` | 左下角 SHIFT 圆钮 |
| 氮气（按住） | `N` | 右侧 NOS 紫色圆钮 |
| 暂停 | `Esc` | 右上角 ⏸ |
| 手柄 | A/RT 油门 · B/RB/Y 升挡 · X/LT 氮气 · Start 暂停 | 无线手柄连接即用，可与键鼠/触屏混用 |

**玩法要点**
- 🏁 倒数灯亮起前轰油门，把指针保持表盘**绿色起步区间**；绿灯瞬间全油门弹射（转速正中区间 = 完美弹射，抓地力加成）。绿灯前就按住油门 = 0.00s 完美预判起步。
- ⚙️ 行进中转速进入**绿色换挡区**按升挡：越接近区间中心越强（完美换挡 = 20% 扭矩加成 + 更快换挡）；换早了顿挫，顶红线会**断油**。
- 🛞 低速全油门会烧胎（冒烟、转速空转、车不快），适当松油门再踩满。
- 🌀 涡轮压力随高转速全油门积攒，升挡泄压——换挡越快损失越少。
- 💨 **氮气**：按住 N 主动释放，扭矩 +35%，满罐约可喷 4 秒，仪表盘左侧紫色 **NOS 条** 显示余量。车轮打滑时喷氮只会加剧空转（动力被烧胎吃掉）——留到高挡位、不打滑时再喷最划算；**完美换挡会补充少量氮气**（完美 +12% / 良好 +5%），喷空后罐自动切断并提示。

## 成长系统

- **性能改装**：引擎（+18% 扭矩/级）、涡轮（+10% 增压/级）、变速箱（-0.065s 换挡/级）、轮胎（+0.11 抓地/级），各 5 级。
- **改装间（独立车间视图）**：车库顶部为全宽车间大图——霓虹灯管 + 向下光锥、"SPEED SHOP · 改装间" 霓虹招牌、工具柜/轮胎垛剪影、反光地坪；性能预估以横条随图展示（APEX Racer 式 Work Shop 体验）。
- **车体套件**：7 种整车车体——「经典街车」（程序化绘制，支持全部自定义）+ 6 种 CC0 贴图车体（蓝色/绯红敞篷、货运卡车、红色超跑、金色/蓝色经典楔形）。选择贴图车体时使用素材原厂涂装，经典专属的涂装/贴花/包围组自动降级提示；随时切回无损恢复。
- **外观定制**：7 件外观包围套件——前包围 / 后包围 / 侧包围 / 尾翼 / 机箱盖（引擎盖）/ 尾气筒（排气）/ **轮眉宽体**（竞技小宽体、铆钉宽体、一体碳纤宽体），各 4 种款式（碳纤、竞技、宽体等风格）；10 种预设车身颜色、6 种贴纸拉花、5 种轮毂；比赛与预览中实时展示（尾焰位置随排气款式变化）。10 名对手车辆中 6 名使用 CC0 贴图车体，其余配备程序化套件组合。
- **灯光与漆面（APEX 式）**：车漆质感 4 种（原厂光泽 / 哑光 / 金属漆 / 镀铬）、大灯颜色 4 种（暖白 / 冰青 HID / 雾紫 LED / 黄金灯，带光锥配色）、底盘霓虹 6 色（冰青 / 霓虹紫 / 落日橙 / 荧光绿 / 樱花粉，地面呼吸光池）；底盘霓虹对贴图车体同样生效，夜行者 Vito、车行老板、传奇·雷霆的座驾原厂就带着底盘灯。
- **整车套件方案**：7 种一键组合（原厂街道 / 街头竞技 / 碳纤性能 / 宽体街霸 / 厂队赛车 / 直线加速 / 极简清洁），卡片缩略图实时预览，一键应用并可手动微调（微调后标记为"自定义"），与涂装自由叠加。
- **自定义涂装编辑器**：任意车身颜色（取色器实时预览）、5 种车身图案（双色车顶 / 渐变涂装 / 斜纹拉花 / 赛道格纹，图案颜色可调）、最多 3 枚自定义贴花（圆形号牌支持自定义文字 / 五角星 / 闪电 / 斜纹块 × 3 种位置 × 3 种尺寸），**贴花可在预览图中直接拖动自由摆放**（悬停高亮、拖动虚线圈、边界钳制、↺ 一键复位），全部即时预览并保存应用至车辆。
- **赛事**：10 名对手（街头新秀 → 车神之巅），胜场解锁下一人；首胜奖励 ×1.5，复赛 45%，败场 30%，评价 S/A/B/C 另有加成。
- 进度自动存档（localStorage），主菜单可重置。

## 项目结构

```
index.html          入口与全部界面骨架
manifest.webmanifest PWA 清单（可安装、独立窗口、横屏、应用图标）
sw.js               Service Worker：预缓存/离线可玩/版本更新（仅 http(s) 注册）
css/style.css       界面样式（暗色霓虹主题）
js/assets.js        第三方 CC0 贴图注册表（贴图车/烟雾，加载失败自动回退程序化绘制）
js/data.js          对手阵容、改装价格表、存档读写
js/audio.js         WebAudio 合成音效（引擎/涡轮/泄压/断油/打滑/氮气/提示音）
js/physics.js       车辆物理（扭矩曲线/抓地与打滑/涡轮/换挡判定/氮气）+ AI 控制器 + 成绩预估模拟
js/render.js        Canvas 渲染（夜景城市/车道/车辆绘制/烟雾粒子/仪表盘）
js/ui.js            菜单/赛事/改装间/结算界面逻辑
js/game.js          比赛流程编排、输入、主循环、客户端外壳（启动画面/PWA/全屏）、结算与奖励
assets/             第三方素材（CC0）+ 应用图标 + 来源与许可证说明（assets/README.md）
test/sim_test.js    无头物理与平衡测试（node test/sim_test.js）
test/dom_test.js    无头 DOM 全流程集成测试（node test/dom_test.js）
test/visual_car.js  用 node-canvas 真渲染 drawCar 输出套件对照图（node test/visual_car.js → test/kit_*.png）
test/gen_icons.js   重新生成 PWA 应用图标（node test/gen_icons.js）
```
