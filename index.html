📖 操作说明

🏁 起步弹射 — 倒数灯亮起前，用油门把转速控制在表盘的绿色起步区间；绿灯亮起的瞬间保持全油门，转速正中区间 = 完美弹射（抓地力加成）。绿灯前就按住油门 = 0.00s 完美预判起步。

⚙️ 换挡时机 — 行进中每当转速进入绿色区间，按 F 升挡。越接近区间中心越强（完美换挡 = 15% 扭矩加成 + 更快的换挡）。换早了会"顿挫"，换晚了顶到红线会断油白白损失时间。

🛞 油门控制 — 低速全油门会烧胎打滑（白烟+转速飙升但车不快）。起步后如发现打滑，适当松一点油门再踩满。

🌀 涡轮增压 — 高转速持续全油门会积攒涡轮压力，爆发额外扭矩；升挡会泄压，换挡越快损失越少。

💨 氮气（N） — 按住 N 释放氮气：扭矩 +35%，一罐约可喷 4 秒。车轮打滑时喷氮只会加剧空转——留到高挡位、不打滑时再喷最划算；完美换挡会补充少量氮气。

🎮 手柄 — 连接后自动生效：A / RT 油门 · B / RB / Y 升挡 · X / LT 氮气 · Start 暂停，可与键盘/触屏混用。

🏅 胜负与奖励 — 先冲过 402m 终点者获胜。胜场解锁下一个对手；起步、换挡、烧胎决定本场评价 S/A/B/C，评价越高金币加成越多。金币可在车库升级引擎/涡轮/变速箱/轮胎。

🎯 第一场比赛

1️⃣ 倒数灯亮起时，按住 空格 轰油门，让指针停在表盘绿色区间里。

2️⃣ 绿灯亮起的瞬间全力油门弹射出去。

3️⃣ 之后每次转速进入绿色换挡区间就按 F 升挡，越准越快！

4️⃣ 高挡位不打滑时按住 N 喷氮气，冲尾速！

💡 打滑冒烟就松点油门；顶到红线会断油，别拖太久。
